## Jalankan

`npm install` lalu `npm run dev`. Untuk memeriksa sebelum deploy: `npm run lint && npx tsc --noEmit && npm run build`.

File baru: `public/ornaments/floral-corner.svg` dan `public/ornaments/botanical-bouquet.svg`.
Styling dapat disesuaikan di `src/app/ornaments.css`.
